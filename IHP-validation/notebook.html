IHP SG13G2 Octagon L2n0 — inductance extraction vs measured¶

This notebook is centered on the existing parameter extraction for the IHP SG13_Octagon_L2n0 benchmark (nominal 2 nH).

For each S-parameter matrix it computes the series impedance

Z(f) = 2 Z0 (1 - S21) / S21
L(f) = Im(Z) / (2πf)
Q(f) = Im(Z) / Re(Z)

and compares the Palace sweep (1–50 GHz, 11 points) with the two pinned IHP measured dies. The measured low-frequency inductance is 1.91–1.93 nH, directly validating the nominal 2 nH benchmark. The 30 GHz result is above the IHP guide differential 1-port SRF (~25.5 GHz). The 2-port series extraction shown here has a different L zero-crossing (~35.5 GHz), so the 30 GHz point is reported without implying a simple SRF agreement.

The IHP OpenEMS runtime was unavailable; the approved fallback is the pinned IHP measured S-parameter data. The notebook documents the OpenEMS settings it mirrors (SG13_L2n0_2port_groundpolygon_mesh1.5um.py: SUBGND→TopMetal1 via ports, 50 Ω, refined_cellsize=1.5 µm, max_cellsize=lambda_air/(sqrt(eps_max)*20) ≈145 µm at 30 GHz/11.9, PEC boundaries, 0–30 GHz/401 points).

def lq_from_s(s, f_hz, z0=b.Z0_OHM):
    z = 2.0 * z0 * (1.0 - s[1, 0]) / s[1, 0]
    l_nh = z.imag / (2 * np.pi * f_hz) * 1e9
    q = z.imag / z.real if z.real != 0 else float("nan")
    return l_nh, q, z


def palace_curves():
    rows = []
    for i, f_ghz in enumerate(np.asarray(sp.freq, dtype=float)):
        s = b.s_matrix(sp, i)
        l, q, z = b.lq_from_s_matrix(s, f_ghz * 1e9)
        rows.append((f_ghz, l, q, s))
    return rows


def measured_curves(label):
    n = rf.Network(str(b.MEASURED[label]))
    z0 = float(np.real(np.asarray(n.z0).reshape(-1)[0]))
    z = 2.0 * z0 * (1.0 - n.s[:, 1, 0]) / n.s[:, 1, 0]
    l = z.imag / (2 * np.pi * n.f) * 1e9
    q = np.divide(z.imag, z.real, out=np.full_like(z.real, np.nan), where=z.real != 0)
    return n.f / 1e9, l, q, n.s


palace = palace_curves()
measured = {label: measured_curves(label) for label in ("die_x2y7", "die_x5y8")}

Experiment matrix¶

Screening at 1 GHz identified the best model: SiO2 top passivation shell + minimal SUBGND pad (shell_ground0), giving 2.099 nH vs measured 1.911/1.932 nH. The full matrix (baseline, shell, ground, PEC, finer mesh, gap port and combinations) is recorded under nbs/data/ihp_validation/experiments/.

Findings¶

  • The measured 1 GHz inductance is 1.91–1.93 nH, confirming the nominal 2 nH benchmark from the extracted data itself.
  • The best experiment (shell_ground0: SiO2 top passivation shell + minimal SUBGND pad) extracts 2.099 nH at 1 GHz, within 10% of both measured dies. It stays near 2.0–2.1 nH through 30 GHz.
  • The 30 GHz point remains a discrepancy in S-parameters and Q; this is reported without implying agreement. The IHP guide's differential 1-port SRF (~25.5 GHz) is distinct from this 2-port series extraction.
  • The comparison uses the same extraction formula for measured and simulated data, so differences come from the EM model/ports/mesh, not from a separate fitting method.

Limitations¶

  • OpenEMS was unavailable; the measured S-parameters are the approved fallback, and the OpenEMS settings are documented above.
  • Palace still uses the coarse 5 µm refined mesh, planar conductor surfaces, and a simplified substrate/port model. The measured fixture reference planes are the TopMetal1 feed ends.
  • The conformal shell is approximated by changing the top passivation material; sidewall shell and the exact OpenEMS ground polygon remain future work.
  • A converged full-wave model and a direct OpenEMS run remain future work.
