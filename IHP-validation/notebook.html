IHP SG13G2 Octagon L2n0 (2 nH) — 30 GHz validation¶

This notebook validates the IHP SG13_Octagon_L2n0 benchmark at 30 GHz.

  • Layout: the IHP /testcase/SG13_Octagon_L2n0 simplified GDS (vendored under nbs/data/ihp_validation/source, Apache-2.0, pinned to IHP-Open-PDK 9439837).
  • Reference: THRU-de-embedded measured GSGSG S-parameters on dies x2y7 and x5y8, with the reference plane at the TopMetal1 feed ends.
  • Simulation: gsim Palace with the authoritative IHP PDK stack, TopMetal2 winding, TopMetal1 feeds/underpass, a SUBGND reference plane, 5 µm refined mesh cells, 70 µm maximum cells, and two interlayer ports from SUBGND to TopMetal1 — the same topology and port definition used by IHP's run_inductor_2port.py / palace_L2n0.py examples.

The IHP OpenEMS runtime (openEMS + CSXCAD) was not available in the validation environment, so the approved fallback is used: the pinned IHP-provided THRU-de-embedded measured S-parameters are the reference, while the OpenEMS script settings are recorded below. The measured 1 GHz inductance is 1.91-1.93 nH, consistent with the nominal 2 nH benchmark. The recorded Palace run is committed so the notebook renders without rerunning the solver.

Model note: this is a single-frequency validation at 30 GHz with a coarse 5 µm mesh, matching the published IHP OpenEMS mesh setting. The measured SRF is ~25.5 GHz and the IHP OpenEMS SRF is ~22.7 GHz, so 30 GHz is above the resonance and the extracted series impedance is dominated by the de-embedded fixture/parasitics. The S-parameter comparison is the robust quantity here; L/Q is reported as an effective series extraction.

def measured_network(label: str):
    """Measured 2-port network for one die."""
    return rf.Network(str(_l2n0.MEASURED[label]))


def lq_from_s(s_matrix: np.ndarray, f_hz: float, z0: float = _l2n0.Z0_OHM):
    """Series L/Q and Z from a 2x2 S matrix."""
    z = 2.0 * z0 * (1.0 - s_matrix[1, 0]) / s_matrix[1, 0]
    inductance_nh = z.imag / (2.0 * np.pi * f_hz) * 1e9
    q = z.imag / z.real if z.real != 0 else float("nan")
    return inductance_nh, q, z


def measured_at(label: str, f_hz: float = _l2n0.TARGET_FREQ_HZ):
    network = measured_network(label)
    point = network.interpolate(rf.Frequency(f_hz / 1e9, f_hz / 1e9, 1, unit="GHz"))
    return point.s[0], lq_from_s(point.s[0], f_hz)

What the IHP OpenEMS script specifies¶

The IHP openEMS example (run_inductor_2port.py) uses:

setting IHP openEMS this notebook
layout L_2n0_twoport.gds / L_2n0_simplified.gds vendored L_2n0_simplified.gds
ports via ports SUBGND → TopMetal1, 50 Ω interlayer ports SUBGND → TopMetal1, 50 Ω
frequency 0–30 GHz, 401 points single 30 GHz validation point
mesh 1 µm refined in conductor, 200 µm margin 5 µm refined, 70 µm max, 150 µm margin (published coarse Palace example)
boundary PEC Palace default absorbing/airbox

The measured S-parameters are the authoritative reference in this notebook. The IHP guide reports measured SRF ≈ 25.5 GHz / peak Q ≈ 23.5 at 9 GHz versus OpenEMS SRF ≈ 22.7 GHz. The two measured dies show the die-to-die spread.

Limitations¶

  • Single-frequency Palace run; the measured sweeps are shown for context.
  • Coarse 5 µm mesh; conductor surfaces and the conformal passivation are not resolved as finely as the published IHP OpenEMS model.
  • The extracted effective series L/Q at 30 GHz is above the measured SRF and is sensitive to the de-embedding/ground reference; S-parameters are the primary comparison.
  • A full OpenEMS run would require the IHP openEMS runtime; the script settings above document the equivalent reference model, and the measured s2p files are the pinned fallback allowed by the validation plan.
